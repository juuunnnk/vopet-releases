# Vopet

Vopet（ボペット）は、会議に参加する 2D キャラクターの Mac アプリです。Zoom や Google Meet に、仮想カメラ **Vopet Camera** と仮想マイク **Vopet Microphone** として参加できます。

- **無料**：すべての機能を無料で使えます。アカウント登録・購入・ライセンス認証はありません。
- **Mac の中で処理**：映像と音声（キャラクターの描画、声の合成、仮想カメラ・マイク）は、すべてこの Mac の中で処理します。
- **動作環境**：macOS 14 以降、Apple シリコンの Mac。声の合成には約 4GB の空き容量と、初回のダウンロードが必要です。

## ダウンロード

[最新版のリリース](https://github.com/juuunnnk/vopet-releases/releases/latest)から `Vopet-<版>.dmg` をダウンロードし、Vopet を「アプリケーション」フォルダへドラッグして開きます。初めて開いたときは、画面の案内に沿って準備します。

アップデートは、アプリが自動で知らせます（設定 > 一般 > アップデート）。

このリポジトリは配布用です（ソースコードは公開していません）。
